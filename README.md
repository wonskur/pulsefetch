# pulsefetch

A minimalist and ultra-fast C++ CLI utility for displaying operating system information and its ASCII logo

## How build
```bash
git clone https://github.com/wonskur/pulsefetch.git
cd pulsefetch
g++ -O3 -flto src/main.cpp -o pulsefetch.exe
```
## or clang
```bash
clang++ -O3 src/main.cpp -o pulsefetch.exe
```
